# Надстройка профиля oss-py-fastapi — шаг 0 (Прояснитель)

Читать сразу после `core/developer/steps/00-clarifier.md`.

Уточнять дополнительно:
- затронутые слои: `api` / `service` / `client` / `queries` / схема БД
  (`layers` профиля);
- касается ли изменение оптимизационного ядра (ограничения/цели `RoutingModel`
  Google OR-Tools) или только CRUD-слоя вокруг него — это разные по риску правки;
- нужен ли реальный вызов OSRM (`/table`, `/route`) или задача решается на
  зафиксированной матрице расстояний из тестовых данных.
