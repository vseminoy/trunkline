# Хуки профиля oss-py-fastapi

## `pre-commit-gate.sh`

Реализация контракта `hooks.pre_commit_gate` (общее описание — `core/developer/ENFORCEMENT.md`).

- Срабатывает только на `Bash`-вызовах, содержащих `git commit`.
- Первым делом вызывает **гейт одобрений** `core/developer/scripts/approval-gate.sh` — тот
  стек-агностичен и лежит в ядре: что считается одобрением, определяет маршрут, а маршрут
  одинаков на любом стеке. Корень пайплайна ищется (`.trunkline/`, затем текущий каталог);
  скрипта нет — шаг пропускается.
- В проекте без `pyproject.toml` не вмешивается — чужой стек пропускается молча.
- Блокирует коммит (exit 2), если `ruff check` или `mypy` падают хотя бы на одном
  проиндексированном `.py`-файле. Проверяются только файлы коммита, не всё дерево —
  диапазон файлов на коммит стоит секунды, полный проход дороже без дополнительной пользы.
- Затем unit-тесты (`pytest -m "not integration" -q`), если `pytest` установлен. Тесты,
  требующие живую БД (PostgreSQL+PostGIS) или OSRM, помечены `@pytest.mark.integration`
  и гоняются CI (`commands.test_integration`), а не предкоммитным гейтом.
- Возвращает агенту вывод упавшей команды.

Требует `jq`, `ruff`, `mypy`, `pytest` в окружении проекта.

Установка и регистрация в `.claude/settings.json` — `core/developer/ENFORCEMENT.md`.
